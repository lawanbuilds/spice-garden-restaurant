# Spice Garden — Design Analysis

## Project Overview

- Project Name: Spice Garden
- Project Type: Restaurant Menu Website
- Reference: reference-ui.png

## Page Sections

1. Header
2. Hero
3. Menu
4. About Us
5. Footer

## 1. Header Analysis

### Layout

- Two main groups.
- Left: Branding.
- Right: Navigation.

### Branding

- Restaurant logo.
- Restaurant name: Spice Garden.
- Tagline: Where Every Bite Tells a Story!

### Navigation

- Menu
- About
- Contact
- Menu is the active link.

### Visual Design

- Background: Deep Burgundy (#3e1314).
- Text: Ivory (#f9f5ee).
- Accent: Gold (#e8b668).
- Style: Premium and elegant.

## 2. Hero Section Analysis

### Content

- Main heading: Our Delicious Menu
- Subtitle: Fresh Ingredients, Amazing Flavours!

### Layout

- Full-width hero background.
- Heading and subtitle on the left.
- Biryani bowl on the right.

### Visual Design

- Food background image.
- Dark gradient overlay.
- Warm and premium appearance.

### Purpose

- Introduce the restaurant menu.
- Grab the visitor's attention.
- Make the main heading easy to read.

## 3. Menu Section Analysis

### Categories

- Starters
- Main Course
- Desserts

### Menu Structure

- Three categories.
- Three food cards per category.
- Total nine food cards.
- All three categories appear in one row.

### Food Card Structure

- Food image on the left.
- Food details on the right.
- Food name.
- Food description.
- Food price.
- Details arranged vertically.

### Visual Design

- Premium and clean card appearance.
- Consistent spacing.
- Clear category separation.

## 4. About Us Section Analysis

### Layout

- Restaurant interior image on the left.
- About Us heading on the right.
- Description below the heading.
- Image and text arranged side-by-side.

### Visual Design

- Light warm cream/peach background.
- Clean and elegant appearance.

### Purpose

- Introduce the restaurant.
- Share the restaurant story.
- Build customer trust.

## 5. Footer Analysis

### Layout

- Dark maroon/burgundy background.
- Three information columns in one row.
- Vertical divider lines between columns.

### Column 1 — Visit Us

- Restaurant address.

### Column 2 — Opening Hours

- Restaurant operating days and timings.

### Column 3 — Contact

- Phone number.
- Email address.

### Bottom Section

- Copyright information.
- Positioned at the bottom of the footer.

### Visual Design

- Gold headings.
- Light text.
- Premium burgundy background.

## 6. Overall Design Direction

### Theme

- Premium
- Elegant
- Warm and welcoming

### Colour Palette

- Primary: Burgundy (#3e1314)
- Accent: Gold (#e8b668)
- Light Gold: (#f3dfba)
- Background: Ivory (#f9f5ee)
- Card Background: White (#ffffff)
- Main Text: (#2c1e19)
- Muted Text: (#7a6b63)
- Borders: (#e8dfd3)

### Typography

- Headings: Cormorant Garamond
- Body: DM Sans

### Responsive Design

- Desktop: Multi-column layouts where appropriate.
- Mobile: Stack content vertically when space is limited.
- About Us: Image above text.
- Footer: Three columns stacked vertically.
